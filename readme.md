# 🎙️ VoiceBridge AI

**VoiceBridge AI** is a modern, browser-based application that converts speech into text and text into speech. It provides a simple and user-friendly interface for speech recognition and voice playback.

## 🌟 Features

- 🎤 **Speech to Text** — Convert spoken words into written text.
- 🔊 **Text to Speech** — Listen to text using your browser's speech engine.
- 🌍 **Multiple Languages** — Select from available recognition languages.
- 🎚️ **Playback Speed** — Adjust the speed of speech playback.
- 📋 **Copy Text** — Copy your transcript with one click.
- 🗑️ **Clear Text** — Clear the transcript whenever needed.
- 🎨 **Modern UI** — Clean interface with a dark theme and colorful accents.
- 📱 **Responsive Design** — Designed to work on desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Speech Synthesis API

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a supported browser, or run it using the VS Code Live Server extension.
4. Allow microphone access when prompted.
5. Select a language and click the microphone button to start speech recognition.
6. Enter text and use the speech playback controls to listen to it.

## 💻 Browser Compatibility

Voice recognition depends on browser support for the Web Speech API. Use a compatible, updated browser such as Google Chrome for the best experience.

Microphone permission is required for speech recognition. Some browser features may require a secure context, such as HTTPS or localhost.

## 🎯 Project Objective

The objective of VoiceBridge AI is to make communication and text entry easier by combining speech recognition and speech synthesis in one accessible web application.
