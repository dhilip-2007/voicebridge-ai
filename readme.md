# 🎙️ VoiceBridge AI

A modern, responsive web application that converts speech to text and text to speech using HTML, CSS, JavaScript, and the Web Speech API.

## 🌟 Features

- 🎤 Speech to Text — Convert spoken words into written text.
- 🔊 Text to Speech — Listen to text using your browser's speech engine.
- 🌍 Multiple Languages — Select from available recognition languages.
- 🎚️ Playback Speed — Adjust speech playback speed.
- 📋 Copy Text — Copy your transcript with one click.
- 🗑️ Clear Text — Clear the transcript whenever needed.
- 🎨 Modern UI — Dark theme with colorful accents.
- 📱 Responsive Design — Designed for desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Speech Synthesis API

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a compatible browser or use the VS Code Live Server extension.
4. Allow microphone access when prompted.
5. Select a language and start speaking.
6. Enter text to use the text-to-speech feature.

## 💻 Browser Compatibility

Voice recognition depends on browser support for the Web Speech API. An updated version of Google Chrome is recommended. Microphone permission is required for speech recognition.

## 🎯 Project Objective

The objective of VoiceBridge AI is to make communication and text entry easier by combining speech recognition and speech synthesis in a single web application.
