# 🎙️ VoiceBridge AI

**VoiceBridge AI** is a modern, responsive web application that converts speech to text and text to speech using HTML, CSS, JavaScript, and the Web Speech API.

## 🌐 Live Demo

🚀 **Try VoiceBridge AI here:**  
https://dhilip-2007.github.io/voicebridge-ai/

## 📌 GitHub Repository

🔗 https://github.com/dhilip-2007/voicebridge-ai/

## ✨ Features

- 🎤 **Speech to Text** — Convert spoken words into written text.
- 🔊 **Text to Speech** — Listen to text using your browser's speech engine.
- 🌍 **Multiple Languages** — Select from available recognition languages.
- 🎚️ **Playback Speed** — Adjust speech playback speed.
- 📋 **Copy Text** — Copy your transcript with one click.
- 🗑️ **Clear Text** — Clear the transcript whenever needed.
- 🎨 **Modern UI** — Attractive dark theme with colorful accents.
- 📱 **Responsive Design** — Designed for desktop and mobile screens.

## 🚀 How to Use

1. Open the [VoiceBridge AI Live Demo](https://dhilip-2007.github.io/voicebridge-ai/).
2. Allow microphone access if prompted.
3. Select your preferred language.
4. Click the microphone button to start speech recognition.
5. Speak clearly and view the generated transcript.
6. Enter text and use the speech playback controls to hear it aloud.
7. Copy or clear the transcript whenever needed.

## 💻 Browser Compatibility

Voice recognition depends on browser support for the Web Speech API. An updated version of Google Chrome is recommended.

**Note:** Microphone permission is required for speech recognition. Availability of speech recognition languages and features depends on the browser.

## 🎯 Project Objective

The objective of VoiceBridge AI is to make communication and text entry easier by combining speech recognition and speech synthesis in a single web application.
